# Slash commands

One file per recurring job in a general insurance brokerage. Each command tells Claude Code exactly which CLI command to run and how to present the result, so the operator never re-explains the job.

The week these were written for: the renewal cycle at sixty, thirty and fourteen days, quotes out to market and chased, placements bound and recorded, mid term changes confirmed by the insurer, claims moved and clients told, brokerage reconciled, and the advice record written while the conversation is still fresh.

Add a command every time the same ask comes twice. Frontmatter needs a `description:` line. The body is the brief.
